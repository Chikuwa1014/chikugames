# まわせ！ちくわルーレット

> 共通のルールは号口（`Chikuwa1014/chikugames`）の `CLAUDE.md` を参照する。ここにはこのゲーム・フォルダだけのことを書く。

ちくわゲームズのルーレットゲーム（v1.0.0）。公開URL：`/roulette/`

- **ひとりで冒険**：ルーレットすごろくRPG。いどうルーレットで進み、敵はこうげき・ぼうぎょのルーレットで倒す。おでん横丁の全5ステージ。ちくわでルーレットを強化。
- **みんなで決める**：最大8人。親が項目（最大256個）を決め、みんな「出てほしくない項目」を1つえらぶ。回転中、針が自分のNG項目に来たときに「はじく！」でルーレットを押し出せる（1回3発まで）。

マルチプレイは対戦オセロと同じく、Cloudflare の仲介（`worker/index.js`）で接続情報を交換して WebRTC で直接つなぐ方式。詳しくは `CLAUDE.md`。
