# つくれ！おでん横丁（旧名：ステージ工房）

ちくわくんが走る「おでん横丁」の 2D アクションステージを作り、その場でテストプレイし、リンクで共有できるブラウザゲームメーカーです。

- 現在のバージョン：v1.5.0（更新履歴は `CHANGELOG.md`）
- ビルド不要。`index.html` 1 枚で動きます。

## 公開のしくみ

chikugames リポジトリの `stage-kobo/` フォルダとして、Worker `chikuwa-games` から公開しています（設定はリポジトリ直下の `wrangler.jsonc`）。
GitHub の `main` ブランチに push すると、Cloudflare が自動でデプロイします。公開パスは `/stage-kobo/` です。

## 共有リンク

ステージのデータは URL の `#st.` 以降に base64 で入っています（サーバー保存なし）。末尾の `.〜` は改ざん検出用のチェック値です。
書き出しは `SK1.` で始まるステージコード（中身は共有リンクと同じ形式）です。
リンクを開くとプレイ専用モードで起動し、編集はできません。

## ローカルで確認する

リポジトリ直下で `npx wrangler dev` を実行し、`/stage-kobo/` を開きます。

## 名前と URL

ゲーム名は v1.4.1 で「ステージ工房」から「つくれ！おでん横丁」に変更しました。配布済みの共有リンクが切れないよう、フォルダ名と URL は `/stage-kobo/` のままです。ブラウザの保存キー（`stage-kobo-v1`、`stage-kobo-progress`）も変えていません。
