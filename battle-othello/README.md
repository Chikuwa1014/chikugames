# バトルオセロ

2台の端末で通信対戦するオセロ。「通常オセロ」と、力をこめて打ち衝撃波でコマを裏返す「バトルオセロ」の2つのルールで遊べます。

- 現在の版：1.0.0（2026-10-24）
- 部屋を作って招待リンク・部屋コード・QRコードで相手を呼びます。通信はちくわゲームズ共通の仲介（`worker/index.js`）で接続情報を交換し、WebRTC で端末どうしが直接つながります。
- プレイヤー名（初期値：親「ちくわ」・子「こんにゃん」）と盤面の色（緑・茶色・将棋・ちくわ）を選べます。不具合はページ下の「不具合の報告」から送れます。

## 更新履歴

- 1.0.0（2026-10-24）：正式版。防御は連打と「輪を円を描くようになぞる」（1周＝防御力4、25周で100）に変更し、擦る防御はなくした。プレイヤー名、盤面の色、不具合の報告（デバッグログ）を追加。攻撃・防御の画面にダメージの数字が重なるのを修正
- β0.1.0（2026-10-23）：ちくわゲームズにベータ版として公開（もとは online-game-test の「対戦オセロ」）
