# ほりほりもぐもぐ

お豆腐（ショート 60³・トール 80³・ベンティ 120³・グランデ 300³ からえらぶ）の中を掘り進んで、鉢合わせた敵をたおす 3D バトル。ちくわゲームズで公開中（2026-10-28 に β版から昇格）。

- ひとりで遊ぶ：おでん横丁のボス 5 体を、5 分以内に全滅させる
- はじめの 60 秒は「ほりほりタイム！」（掘ってアイテム集め。攻撃・罠なし、落ちたら天井へ）
- みんなで遊ぶ：2〜8 人。ほかのちくわ君を全滅させたら勝ち（親が抜けても続く）
- アイテム 9 種（出汁ピストル・からし地雷・大根・おたまレーザー・味玉・しらたき・ごぼうバット・お味噌・ビッグ味玉）
- 床を掘り抜くと奈落のおでん鍋へ
