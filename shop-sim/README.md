# ちいさなお店（商品販売シミュレーター）

> 共通のルールは号口（`Chikuwa1014/chikugames`）の `CLAUDE.md` を参照する。ここにはこのゲーム・フォルダだけのことを書く。

ブラウザだけで動く静的ゲームです。サーバーやライブラリは不要です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み。css/js を読み込むだけ |
| `css/style.css` | 見た目（色・レイアウト・ダークモード） |
| `js/data.js` | 数値表（商品・季節・天気・難易度・セキュリティなど）。**数値の調整はここ** |
| `js/util.js` | 小さな共通関数 |
| `js/state.js` | ゲームの状態 `state` の初期化・保存・読み込み、ログ |
| `js/rules.js` | ルール計算（購買力・費用・ノルマなど） |
| `js/events.js` | イベント（盗難・セキュリティ・商品イベント） |
| `js/actions.js` | プレイヤー操作（補充・投資・融資・預金・開店） |
| `js/engine.js` | 時間の進行（営業中の1秒・閉店・翌日） |
| `js/pixel.js` | ドット絵の描画 |
| `js/share.js` | 倒産ポップアップとSNS共有 |
| `js/save.js` | セーブデータのファイル書き出し・読み込み、セーブコード |
| `js/amazake.js` | かまくらボーナスと甘酒ミニゲーム |
| `js/achv.js` | 実績 |
| `js/debuglog.js` | デバッグログの記録と送信 |
| `js/ui.js` | 画面の描画とボタン操作 |
| `js/main.js` | 起動処理（最後に読み込む） |
| `build.py` | 1つのHTMLにまとめる（`dist/shop-sim.html`） |

共有・セーブ・デバッグ送信の土台は、ちくわゲームズ共通部品 `../common/v1/`（`build.py` が中に埋め込みます）。

読み込み順は `index.html` のとおりです。ファイル間で関数・定数を共有するため、順番を変えないでください（`main.js` が最後）。

## 実行・公開

- 実行: `index.html` をブラウザで開く。
- 1ファイル化: `python3 build.py` → `dist/shop-sim.html`
- 公開: そのままの複数ファイルを GitHub Pages / Cloudflare Pages などに置けます。

## 修正するときの目安

- 数値（価格・確率・難易度）を変える → `js/data.js`
- ルールの計算式を変える → `js/rules.js`
- イベントを足す・変える → `js/events.js`
- 画面の文言・ボタン → `js/ui.js`
- 見た目 → `css/style.css`
- ドット絵 → `js/pixel.js`

## セーブ

`state` オブジェクト全体を `localStorage`（キーは `js/data.js` の `KEY`）に保存しています。
状態の項目名（`sk`, `sl`, `ss` など）を変えると既存のセーブが読めなくなるため、`KEY` を変えてください。

端末をまたぐときは「⚙設定」タブのファイル書き出し、またはセーブコード（1行の文字列）を使います。
