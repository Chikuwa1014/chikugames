## 0-2. 台風・大雪イベントの仕様変更 【実装済み v1.1.0】
現状（`js/engine.js` の翌日予告、`js/events.js` の `rollEvents`）：
- 台風は夏・秋、大雪は冬に、天気予報と無関係に抽選。予告は約80%で的中
- 台風：棚が減り、在庫がすべて0、幸福度-5 ／ 大雪：強制休業（購買力0）

### 台風
- [x] 発生するのは、翌日の天気予報が「曇り」か「雨」のときだけ（季節は今と同じ夏・秋）
- [x] 台風の予告が出たときだけ、閉店後に「土嚢を積んで耐える」ボタンを表示
- [x] 押すと55%で被害なし。被害なしなら幸福度+25、店員の士気アップ（翌日だけ店員の能力+1段階）

### 大雪
- [x] 発生するのは、翌日の天気予報が「曇り」「雨」「雪」のときだけ（季節は今と同じ冬）
- [x] 大雪の予告が出たときだけ、閉店後に「かまくらを作る」ボタンを表示
- [x] 押すと55%で「かまくらボーナス」：お客さんに甘酒を振る舞う（店員の有無に関係なく発生）
- [x] 甘酒ミニゲーム：ポップアップ表示。上7割に甘酒を配るドット絵のアニメーション、下3割に甘酒ボタン（全画面でなくてよい）
- [x] 10秒間ボタンを連打し、連打数に応じて売上金の報酬（原価0）

### 決定事項（2026-10-22）
- 土嚢・かまくらのボタンは無料
- 予告が空振りだった日にボタンを押していた場合は、備えのため休業（幸福度は店休日と同じ扱いで回復）
- かまくらボーナス発生時は、大雪の強制休業を取り消す（休業中にかまくらで遊んでいたらお客さんが来た、という体）
- 大雪の朝：かまくらを作るアニメーションを表示し、ログに「かまくらを作っています」。12:00 から甘酒ボーナス（ミニゲーム）開始
- 連打の報酬は難易度で変える
- 土嚢・かまくらが失敗（45%）したときは、今と同じ被害（台風：棚減少・在庫0・幸福度-5 ／ 大雪：強制休業）
- かまくらボーナスの日の流れ：朝はかまくら作り（通常販売なし）→ 12:00 に甘酒ミニゲーム開始（10秒）→ 終了後そのまま閉店

### 甘酒の報酬（決定 2026-10-22）
- 1回あたり＝解放済み商品のうち一番安い商品の販売価格（アップグレード・粗利率を反映、`priceOf`）× 難易度倍率
- 難易度倍率：イージー1.2／ノーマル1.5／ハード2.0／インフェルノ3.5
- 連打数の上限なし、オートクリック対策なし
- 原価0なので全額が利益。今月の売上（ノルマ）と累計売上に加算
- 目安（ハード・粗利40%）：おにぎり¥133×2.0×70回＝約1.9万円

### 終了時の一言（連打数、決定 2026-10-22）
- 0回：「だれも来なかった…」
- 1〜29回：「ちらほら」
- 30〜69回：「大にぎわい」
- 70〜119回：「行列ができた！」
- 120〜299回：「指がつりそう！」
- 300〜599回：「町じゅうが甘酒まみれ」
- 600〜999回：「指が見えない…」
- 1,000回以上：「伝説の甘酒屋」
