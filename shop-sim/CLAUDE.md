# ちいさなお店（商品販売シミュレーター）— 開発メモ

全ゲーム共通のルールは号口（`Chikuwa1014/chikugames`）の `CLAUDE.md`。ここにはこのゲームだけのことを書く。
タスクは `claude/未実装タスク.md`（セッションの最初には読まない。いちばん優先の項目は 8 章）。完了した項目はチェックを付け、新しい要望はそこに追記する。

## 1. 概要

季節や天気、お客さんの動きを読んで商品を仕入れて売る経営シミュレーション。稼いだお金で商品を増やし、棚を広げてお店を育てる。
ブラウザだけで動く静的ゲーム（HTML/CSS/JS、ライブラリなし、スマホ優先・横画面も可）。共有・セーブ・デバッグ送信の土台は共通部品 `../common/v1/`（号口（`Chikuwa1014/chikugames`）の `CLAUDE.md` の 15 章）。現在のバージョンは `js/data.js` の `VERSION`（v2.0.0・2026-10-28。履歴は `CHANGELOG.md`、画面の更新履歴は `js/data.js` の `CHANGES`）。
仕様の詳しい中身は末尾の「付録：ゲームの仕様」。

## 4. 保存キー

- 自動保存：localStorage の `js/data.js` の `KEY`。項目名を変えたときは `KEY` を変える（古いセーブと混ざらないように）。
- `state` の形を変えたときは `js/save.js` の `SAVE_VER` を上げ、`loadFix` に古いファイルの移行処理を書く（ファイルとセーブコードの両方に効く）。
- セーブデータのファイル書き出し・読み込みは付録の「セーブデータ」。
- 遊び方を見たか（v2.0.0〜）：localStorage `shop-sim-tutorial`（`'1'`＝見た・飛ばした）。ゲームのセーブ・引っ越しには入れない。`js/tutorial.js` の `TUT_KEY`。
- タブバーを隠したか（v2.0.0〜）：localStorage `shop-sim-tabbar`（`'1'`＝隠す）。見た目の好みだけなので、ゲームのセーブ・引っ越しには入れない。`js/ui.js` の `tabBar`・`TBAR_KEY`。
- 実績：localStorage `shop-sim-achv`（`{ id: { at, diff } }`）。ゲームの保存とは別で、やり直し・倒産でも消えない。実績の `id`（`tot<金額>`・`day<日数>`・`sv<金額>`・`inf<日数>`）は公開後に変えない。

## 付録：ゲームの仕様（実装済み）

### 1日の流れ
- 棚の補充ボタン：「+N」（N＝最大容量の10%、端数切り上げ・最低1）と「満タン」。
- 閉店後 → ①開店準備（補充だけ）→ ②開店（販売と補充）→ ③閉店後（投資・お金・店休日・天気予報）。
- 営業時間は 5:00〜23:00 の範囲で指定。1時間＝5ティック。速度は ⏸・×1・×2・×4・×8（v1.4.0〜タブの行の右端。倍速は押すたびに切り替え）。
- 1ヶ月＝7日。季節は実際の1年と同じく3ヶ月ごと（v1.3.0〜。1ヶ月目＝4月：春4〜6月・夏7〜9月・秋10〜12月・冬1〜3月。`START_MONTH`・`seaOf`・`calOf`）。購買力の倍率は春1.1・夏1.25・秋1.0・冬0.98。
- 日付の表示は「🌸春 / 5月2日目（通算2ヶ月9日）」（暦の月・その月の何日目・通算の月数と日数）。天気は晴1.125・曇1.0・雨0.98・雪0.95（雪は冬のみ）。
- 購買力＝季節×天気（炎上中は難易度ごとの倍率：イージー0.9・ノーマル0.8・ハード0.7・インフェルノ0.5）。

### お客さん・購買欲
- 来店数＝(0.35＋広告×0.18＋棚数×0.08)×購買力×(0.8＋購買欲/250)×ブースト×粗利補正×決済補正×難易度補正。
- 男女は半々。男性は腕時計・イヤホン、女性は化粧品・米袋を買いやすい。高い商品ほど選ばれにくい。
- 購買欲：販売+2、取り逃がし-3、毎ティック(購買力-1)×4-0.6。100で10ティック来店2倍、終了後50。店休日+8。

### お金
- テナント料：4000×1.6^(棚数-2)×改定倍率×難易度倍率（月末払い）。
- 店員の時給：愛知県最低賃金1,195円×難易度倍率。7時前・22時以降は125%、病気中150%。月末払い。
- 自分の月収（スライダー、0〜60万）。中央値の目安は月33万。
- ノルマ＝max(損益分岐点, 前月売上×難易度の前月比)。損益分岐点＝(テナント料＋融資返済＋月収＋店員給料)÷実質粗利率。未達で幸福度-3、達成で+3。ノルマ欄の下に内訳（損益分岐点・前月比）を表示する。
- 融資：3万〜1億。150万以上は月平均売上×10まで、36・48・60回払いも可。利子はハード以下15%・インフェルノ25%（13ヶ月超は上乗せ、60ヶ月で2倍）。同時3件まで。
- 預金：1,000円単位。月末に所持金がマイナスなら自動で引き出し。全難易度で使用可。
- 決済方法（最大3つ）：1つにつき客足×1.2、月末に売上の3.75%の手数料。

### 投資（閉店後、病気中は不可）
- 棚（最大12、増やすたびに上位商品を解放）、容量（10→…→5,000の17段階）、広告（Lv20）、店員（最大12人）、店員の能力（Lv10、補充量5×2^Lv、Lv10で満タン、費用は人数に比例）、セキュリティ、商品アップグレード。
- 3ヶ月ごとの月末に、期間中に棚を増やしていなければ強制増設。
- 商品は12種（おにぎり・のみもの・おかし・文房具・雑誌・化粧品・イヤホン・米袋・健康食品・腕時計・スマートフォン・乗り物）。最初はおにぎりとのみもの。
- アップグレードは累計販売 50/100/250/500/1000/5000/10000 個で権利解放、お金を払って適用（原価+40%/段階）。

### セキュリティ
- レベルアップとストック購入は別。ストック最大5、破損期間が来ると0。
- 盗難のあった日に1ストック消費（同じ日の強盗・窃盗・泥棒をまとめて守る）。
- Lv1お守り-5,000円／Lv2おふだ-1万／Lv3仏壇-10万／Lv4 AIカメラ1割／Lv5赤外線5割／Lv6能面8割（Lv4〜6は最低10万保証）／Lv7〜10は10割。
- 破損：Lv1〜3・10は12ヶ月、Lv4・5・8は3ヶ月、Lv6・9は6ヶ月、Lv7は1ヶ月。
- Lv10が作動すると1ヶ月休業（投資・融資は可、幸福度は回復しない）。
- 強盗にセキュリティが効いたときは、ノルマゲージを0にしない。

### 幸福度・病気
- 営業日は長時間ほど低下（9時間で±0）。休業日の回復：80%以上+20、50〜79%+18、35〜49%+10、15〜34%+5、5〜14%+2、0〜4%+1。
- 病気の確率（毎日）：80%以上0、50〜79% 5%、35〜49% 10%、15〜34% 15%、5〜14% 25%、0〜4% 45%。7日休業（店員がいれば営業継続、給料150%）。
- 20%未満が14日続くとうつ病で14日休養（復帰時50%）。5%未満が7日続くとゲームオーバー。
- イージーは病気・うつ病・この種のゲームオーバーなし。

### 難易度
| | イージー | ノーマル | ハード | インフェルノ |
|---|---|---|---|---|
| 初期資金 | 3万 | 1万 | 5千 | 3千 |
| 病気・月収 | なし | あり | あり | あり |
| 融資・粗利率の調整 | 不可（非表示、粗利50%） | 不可（非表示、粗利45%） | 可 | 可 |
| イベント倍率 | 0.5 | 1.1 | 2.2 | 15 |
| 倒産ライン（ノルマ比） | 30% | 20% | 10% | 5% |
- インフェルノのみ、店員の「負の感情モード」（能力マイナスで商品を盗む）。

### イベント（主なもの）
- 車の突っ込み、台風（夏秋）、大雪（冬、強制休業）、テナント料改定（月初）、大地震（投資リセット）、強盗、季節ブーム、決済方法追加、従業員の窃盗、ダイヤモンド万年筆の泥棒（店員1〜12名解雇・士気低下）。
- 大雪と台風は、前日の閉店後に予告（予告の約80%で発生、20%は空振り）。台風は翌日の予報が曇り・雨、大雪は曇り・雨・雪のときだけ。
- 予告が出たら閉店後に無料のボタン（`state.prep`）：台風「🧱 土嚢を積んで耐える」、大雪「⛄ かまくらを作る」。どちらも成功率55%、失敗は通常の被害。予告が空振りで押していた日は備えのため休業（店休日と同じく幸福度回復）。
- 土嚢の成功：被害なし、幸福度+25、台風の次の日だけ店員の能力+1段階（`state.mbDay`）。
- かまくらの成功（`state.kama`）：強制休業を取り消し、開店準備なしで開店。通常の販売・店員の給料なし（休業扱いで幸福度回復）。12:00（開店が12時以降なら開店直後）に時間を止めて甘酒ミニゲーム。
- 甘酒ミニゲーム：上7割にドット絵、下3割に甘酒ボタン。最初に押してから実時間10秒の連打。1杯＝解放済みで一番安い商品の販売価格×難易度倍率（`DF.ama`：1.2／1.5／2.0／3.5）。今月の売上・累計売上に加算。連打数で一言（0:だれも来なかった… ～ 1000+:伝説の甘酒屋）→「閉店する」で閉店。
- 初月は棚が減らない（修繕費のみ）。
- 各商品の最終段階で専用イベント（爆発・ツモ・バナナの皮・超セレブ・パパ活・おにぎりブーム・教育ママ・炎上・6台の事故など）。

### 倒産（ゲームオーバー）
- 資金が倒産ライン（ノルマ×難易度の割合、千円未満切り捨ての負の値）を下回る。
- 全棚の在庫が0で資金がマイナス（「もうダメだ…」）。
- 倒産すると画面中央にポップアップ（理由・リザルト画像・共有欄・最初からやり直す・閉じる）。
- 閉じると `state.ovx = true`。営業タブの「結果を見る・シェアする」で再表示。
- 「設定」タブの「🔄 最初からやり直す」（赤い枠のカード。2回押し。1回目でボタンが赤くなる）でも再開できる。

### 倒産時のSNS共有（`js/share.js`）
- 倒産ポップアップの中に共有欄：「結果をシェア」「画像を保存」、文面の窓（読み取り専用）と「文面をコピー」。
- 文面「ちいさなお店を開いたけど倒産しちゃった！残念😢」＋ #ちくわげーむず ＋ 今開いているページのURL。
- 結果をシェア：端末の共有メニュー（Web Share API）で文面＋リザルト画像。使えないときはXの投稿画面（画像は手で添付）。
- リザルト画像は1200×630：ドット絵（1.5倍）、倒産理由、難易度・営業日数・累計売上（`state.tot`）・最終所持金・預金・棚の数。倒産時に先に作っておく。

### セーブデータ（`js/save.js`、「⚙設定」タブ）
- 自動保存は localStorage（`KEY`）。ファイルとセーブコードは端末をまたぐバックアップ用。
- 書き出し：`{ game:'shop-sim', v:SAVE_VER, at, data:state, key }` の .json（v1.1.x までは `data` の代わりに `state`。読み込みは両方できる）。ファイル名は `ちいさなお店_難易度_○ヶ月目_日時.json`。
- 読み込み：ファイルを選ぶと概要（難易度・時期・所持金・保存日時）を表示 →「このデータで再開」で反映。別ゲーム・壊れたファイル・新しい版はエラー表示。
- 足りない項目は `fresh()` の初期値で埋める。反映後に `applyDiff`・`applyUp` で再計算し、営業タブへ。
- 営業中（開店〜閉店）は不可。開業前・開店準備・閉店後・倒産後は可。
- `SAVE_VER` 2：土嚢・かまくら（`prep`・`kama`・`mbDay`）を追加。
- セーブコード（v1.2.0〜）：「📋 コードをコピー」で同じ包みを `CK1.<deflate＋base64url>.<チェック値>`（約750文字〜）にしてコピーし、欄にも出す（コピーできない端末は長押しで）。「⌨ コードで読み込む」に貼ると、ファイルと同じ確認（概要→「このデータで再開」）。欠け・書き換え・別ゲームのコードはチェック値ではじく。

### 実績（v1.3.0〜、`js/achv.js`）
- 18個：累計売上（`state.tot`）1億・10億・100億・1000億・1兆／営業（通算日数 `state.day`）10年・50年・100年／貯金（預金残高 `state.sv`）1000万・1億・10億・100億・1000億・1兆／インフェルノで（倒産せずに通算日数）6ヶ月・1年・5年・10年。
- 1年＝12ヶ月＝84日（`YEAR`）。判定は閉店のあと（`endDay`）と預金の操作のあと（`svMove`）。
- 解除の瞬間は画面下にトースト（`CG.toast`）。所持金の行の右端のバッジ「🏅 解除数/18」をタップするとポップアップ（`#achm`）で一覧（解除日と難易度、未解除は🔒と進み具合のバー）。
- リセット（v1.4.0〜）：一覧の下の「🗑 実績をリセット」→ ページ内の確認（「消す」「やめる」）。`shop-sim-achv` を空にする。条件を満たしたままの実績は次の閉店のあとに再び解除される。

### 画面
- 上部固定：屋根・所持金のカードと実績バッジ（1行目）・難易度/季節/日付/通算/天気のチップ（2行目・右揃え）・ドット絵（店・季節・天気・夜・店員・お客さん・セキュリティ）。一時停止・倍速は絵の右下（`#spd`。絵を閉じたときと横画面は絵の下）。タブは画面の下に固定（v2.0.0〜）。
- 画面を広く使う（v2.0.0〜）：店の絵は端まで広げ、見出し（`.shn`・`#ph`・`#pw`）は絵の上に重ねる（看板にかからないよう左右に寄せる）。幅 900px 以上と横画面は2列で、時計 `#clk` とゲージのカードを左の列へ移す（`place`）。
- 見た目（v2.0.0〜）：ミント×コーラル。ID・`data-a` は v1.x と同じ（テストがそのまま使える）。見た目だけを変えるときは `css/style.css` と、`js/ui.js` の HTML の組み立て（チップ・タブ・`#spd`）だけを触る。
- セキュリティのストック残数（`#secn`、v1.4.2〜）：ドット絵の右上に「🛡×数」。0のときは出さない。
- 営業中の現在時刻（`#clk`、v1.4.1〜）：営業タブの購買欲ゲージの上。18px・太字。
- マイナスのイベントの日（v1.4.1〜）：`addEvent(t, true)` で `markBad` → `state.bad = state.day`。その日（翌日へ進むまで）は空が赤く、カラス（`pxCrows`）、お客さんがうつむいて（`pp` の `down`）0.6倍の速さで歩く。起きた瞬間は `#px` に `shake`。理由ラベル（v1.5.1〜の `#badw`・`state.badWhy`）は v1.5.3 で廃止し、v1.5.2 のお知らせ（`#bnote`）に統一。
- 月末の支払い予想（v1.5.3〜）：`payForecast()`（`js/rules.js`。月末の閉店処理 `engine.js` と同じ式）を、店の絵の左下 `#payf`（黒・透過60%・白字）に常に表示（`js/ui.js` の `render`）。式を変えたら両方そろえる。
- 幸福度ゲージの下のプルダウン（v1.5.3〜）：`<details id="dtl">`（`index.html`）。閉じている間の要約 `#dsum` は状態（`#hs`）の一言、無ければ「月末まであと◯日」。開閉は再描画しても保たれる。
- 悪いイベントのお知らせ（v1.5.2〜）：`markBad(t)` が `noticeBad(t)`（`js/events.js`）を呼び、店の絵の上の `#bnote`（`js/ui.js` の initLayout で作る）に「⚠ イベント名」を `NOTICE_MS`=800ms 出し、`NOTICE_FADE`=300ms でフェードアウト。複数はキュー（`noticeQ`）で順に出す。実時間（ゲーム速度・一時停止に関係なし）。良いイベントは出さない（ログのみ）。
- イベントの絵（v1.5.0〜、`js/pixelfx.js`）：イベントが起きた日だけ店の絵に反映し、翌日（`state.day` が変わる）に戻る。`addEvent` が文面から種類を決めて `state.fx`（種類の配列）と `state.fxd`（その日）に記録する（セーブに入る。無くても動くので `SAVE_VER` は上げない）。台風の浸水（水没）・土嚢・大雪・車・6台の事故・爆発・大地震（`#px.quake` で揺れ続ける）・強盗・窃盗・万年筆泥棒・超セレブ・パパ活・ツモ・バナナ・おにぎり・教育ママ・炎上・テナント料（↑赤／↓青）・ブーム・決済対応。休業の清掃（`state.clean`／`cleanDay`）はモップがけ。新しいイベントを足したら `FXK` にも足す。夜（閉店後を含む）は窓・ドアを暗さの上に描き直すので、そのあとで人物（`pxPeople` と `pxFxTop` の `pp` だけ。`pxOnlyPp` で人物以外を塗らない）と窓のステッカー（`pxFxPay`）を描き直している（v1.5.1〜）。窓に付くもの（割れた窓など）を足すときも、夜の描き直しに注意。
- 営業タブのログ欄（`#lg`）：4行分の枠でスクロール。長い行は折り返して2行目以降を1文字下げる（v1.5.2〜。`.log div` の `padding-left:1em; text-indent:-1em`）。直近200件＝営業開始から終了まで（v1.5.1〜。それまでは50件で、営業時間を長くすると前半が読めなかった）（売れた商品は1秒ごとに時刻つきでまとめて1行、イベントは太字）。セーブには入らない。
- 横画面（横向きで高さ 560px 以下）：左に上部固定の部分、右にタブの中身（`css/style.css` の末尾の `@media`）。
- タブ：🏪営業・🛒投資・💰お金・⚙設定（画面の下のタブバー）。スクロールは上の部分とタブバーの間だけ。
- 操作の説明文は画面に出さず、小さな「？」（`helpIcon(キー)`）を触ったときだけフロートで表示。文言は `js/data.js` の `HELP`。ほかを触る・スクロール・タブ切り替えで閉じる。
- 設定タブの一番下に「📝 更新履歴」（最新だけ表示、過去は「過去の更新履歴」を開く。つくれ！おでん横丁と同じ形）と「ちいさなお店 v（`VERSION`）」・著作権表記（`COPYRIGHT`、© 2026 ちくわげーむず）。
- ゲージ（購買欲・ノルマ・幸福度）の説明は見出し横の「？」。購買力は「🏪 店の様子」の行の右端に表示（内訳は title）。
- 画面に残す説明：投資の説明、難易度選択の説明。月末の支払い（テナント料・返済・給料未払）とノルマの残り日数はゲージの下に常に表示。
