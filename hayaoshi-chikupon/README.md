# 早押し！ちくぽん！

ちくわゲームズの早押しゲーム（1.0.0）

- **ひとりで**：「いろ」「おと」「しんどう」の合図で反応のはやさを5回はかる。合図の前に押すとお手つき。ベスト記録は端末に保存。
- **みんなで**：出題者（親）が部屋を作り、回答者（子）が部屋コード・招待リンク・QR で参加（最大8台）。出題者（親）の「回答許可」で合図を出し、いちばん速い回答者（子）が回答権。出題者（親）が ○ か × を決める。「📚 スタック」では押した人全員が 1番との差の順に並び、×だと次の人へ。全員×なら「🀄️流局🐉」。

マルチプレイは、Cloudflare の仲介（`worker/index.js` の `MultiRoom`）で接続情報を交換して WebRTC で直接つなぐ方式。詳しくは `CLAUDE.md`。ルールは号口（`Chikuwa1014/chikugames`）の `CLAUDE.md` を参照。
